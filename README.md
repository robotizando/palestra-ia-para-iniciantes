# palestra-ia-para-iniciantes
Palestra ensinando pessoas como essas maquinas de "pensar" funcionam

## Oficina de IA

Material da oficina, na pasta [`oficina-ia/`](oficina-ia/):

- [`programacao.md`](oficina-ia/programacao.md): programação da oficina, bloco a bloco.
- [`apresentacao/`](oficina-ia/apresentacao/): fonte dos slides (`deck.json` com a ordem e as seções, e um HTML por slide em `slides/`).

A versão viva da apresentação está publicada em https://claude.ai/artifact/H3THoFiSSpR9ftCQrV9w39. Edições feitas lá não voltam sozinhas para esta pasta.
