Não é para decorar: é para saber que existe e onde procurar. Conversa: Grok fica dentro do X (antigo Twitter) e é bom para o assunto do momento; DeepSeek é chinesa e grátis, mas não colar dados de cliente nela (vale para todas). Pesquisa: o Perplexity mostra de onde tirou a resposta, então dá para conferir; IA também inventa. Imagem: para o card de Instagram vamos usar o Claude, mas Canva com IA é ótimo para quem já usa Canva. Vídeo: só citar, o papo é no bloco 8. Voz e música: ElevenLabs para narrar vídeo ou anúncio; Suno para jingle; criarmusicas.com.br como exemplo brasileiro. Programação: Lovable cria site conversando; o resto é para quem programa. Lembrar que nomes, preços e planos grátis mudam o tempo todo.
