Troquei uma palavra: agora “ela” é a caixa.

Atenção = para cada palavra, quanto olhar para cada uma das outras. É assim que a IA entende o contexto. (Porcentagens ilustrativas.)

Exemplo clássico de pesquisa em linguagem, adaptado para o bolo. As duas palavras são femininas de propósito: a gramática não ajuda, só o sentido. Leia as duas frases em voz alta e pergunte à turma quem é "ela" em cada uma. A gente resolve sem pensar; a IA resolve com a atenção: na hora de entender "ela", ela olha para todas as outras palavras e dá um peso para cada uma. Com "grande", quase todo o peso vai para "torta" (é a torta que é grande demais); com "pequena", vai para "caixa". Mudou uma palavra no fim, mudou para onde a atenção olha. As porcentagens são ilustrativas: cada modelo tem muitas "cabeças" de atenção e cada uma olha de um jeito.
